# منصة فواتير مكنون المدينة

أداة بصفحة واحدة لإنشاء فواتير ضريبية بهوية **شركة مكنون المدينة**، مع رمز QR ضريبي متوافق مع هيئة الزكاة والضريبة والجمارك، وتصديرها PDF. لا تحتاج خادماً ولا قاعدة بيانات.

## الاستخدام
1. افتح الرابط (أو `index.html` محلياً).
2. عبّئ **الفاتورة** و**العميل** و**البنود** — المعاينة تتحدّث مباشرة.
3. اضغط **تصدير PDF** ثم اختر «حفظ كـ PDF» (فعّل «الرسومات الخلفية» إن لم تظهر الألوان).

كل شيء يُحفظ داخل متصفحك فقط (مسودة، سجل الفواتير، العملاء، البنود الجاهزة). استخدم «السجل ← نسخة احتياطية» لنقله بين الأجهزة.

## المزايا
- أنواع: فاتورة ضريبية، مبسطة، إشعار دائن، إشعار مدين.
- حساب الضريبة (15% / 0% / معفى) بدقة الهللة، أسعار شاملة أو غير شاملة، خصم لكل بند.
- تفقيط المبلغ بالعربية، ترقيم تلقائي، عملاء وبنود محفوظة.
- توزيع تلقائي على صفحات A4 عند كثرة البنود.
- QR بصيغة TLV/Base64 (المرحلة الأولى): اسم البائع، الرقم الضريبي، التاريخ والوقت، الإجمالي، الضريبة.
- ختم وتوقيع وبيانات دفع قابلة للتعديل.

## هيكل المشروع
```
index.html        الصفحة
css/base.css      واجهة المنصة (فاتح/داكن)
css/invoice.css   مستند الفاتورة A4 والطباعة
js/brand.js       الهوية وبيانات الشركة الافتراضية
js/calc.js        حسابات الضريبة بالهللات
js/numwords.js    التفقيط
js/zatca.js       ترميز QR الضريبي
js/render.js      رسم الصفحات والتوزيع
js/app.js         الحالة والتخزين والواجهة
js/vendor/        qrcode-generator (MIT)
assets/           الخطوط (ثمانية سانس) والشعارات والختم
```

## ملاحظات نظامية
- تاريخ نفاذ التسجيل في الضريبة **01/10/2026**؛ تنبّه المنصة لأي فاتورة بضريبة قبله.
- الـ QR هنا للمرحلة الأولى (الإنشاء). إن أُبلغت الشركة بالمرحلة الثانية (الربط والتكامل) فيلزم نظام مرتبط بمنصة فاتورة.
